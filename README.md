# 💸 Donate App

Приложение-сервис для отправки донатов на благотворительные нужды. Реализовано на чистом JavaScript с использованием компонентного подхода (мини-фреймворк на базе класса `Component`).

---

## 🚀 Запуск

```bash
npm install
npm start
```

Приложение откроется в браузере автоматически.

---

## ⚙️ Функциональность

- Ввод суммы доната от **$1 до $100**
- Валидация поля ввода — кнопка заблокирована при некорректном значении
- При отправке донат мгновенно появляется в списке с датой и суммой
- Автоматический пересчёт итоговой суммы всех донатов
- Удаление доната из списка с пересчётом итога

## 🧱 Архитектура

Приложение построено на компонентном подходе. Каждый компонент — это класс, наследующий от `Component`. Общение между компонентами происходит через **props** и **callback-функции**.

### Иерархия компонентов

```
App
├── Form
└── List
    └── ListItem × N
```

### Поток данных

```
Пользователь вводит сумму
    ↓
Form.handleInput() → валидация → блокировка/разблокировка кнопки
    ↓
Пользователь нажимает кнопку
    ↓
Form.handleSubmit() → вызывает props.onSubmit(amount)
    ↓
App.onItemCreate(amount) → создаёт ListItem, обновляет total
    ↓
List.addItem(item) → добавляет элемент в DOM
```

## 📦 Компоненты

### `Component` (базовый класс)
Абстрактный класс. При создании экземпляра автоматически вызывает `setup(props)` и сохраняет входные параметры в `this.props`.

### `App`
Корневой компонент. Хранит общее состояние приложения:
- `this.state.total` — сумма всех донатов
- `this.state.donates` — массив экземпляров `ListItem`

Передаёт `onItemCreate` в `Form` через props, а `onItemDelete` — в каждый `ListItem`.

### `Form`
Компонент формы. Управляет своим состоянием (`amount`). Содержит геттер `isValid` для валидации введённого значения. При успешной отправке вызывает `props.onSubmit(amount)`.

### `List`
Компонент-контейнер для списка. Предоставляет метод `addItem(item)`, который добавляет новый `ListItem` в DOM.

### `ListItem`
Компонент одного доната. Хранит `id`, `date` и `amount`. При нажатии на кнопку "Удалить" вызывает `props.onDelete(amount)` и удаляет себя из DOM.
